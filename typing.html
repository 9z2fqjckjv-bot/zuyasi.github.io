タイピング練習

GitHub Pagesでそのまま動く、ローマ字入力のタイピング練習ツールです。制限時間を選んで、WPM・正確率・ミス数を確認できます。

残り時間 60
WPM 0
正確率 100%
クリア数 0

お題

スタートを押すとお題が表示されます。

スペースや記号もそのまま入力します。

ready

スタート後、表示されたローマ字を入力してください。

ベスト記録

  1. まだ記録がありません。

使い方

  • 「スタート」を押すとタイマーが始まります。
  • 入力が合っている文字は緑、違う文字は赤で表示されます。
  • お題を最後まで入力すると、自動で次のお題へ進みます。
  • ベスト記録はこのブラウザ内に保存されます。
